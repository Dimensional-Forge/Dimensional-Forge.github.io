RS-25 PID Heat Map Tool

Propulsion Systems Analysis Intern · Liquid Engine Systems Branch (ER21) · NASA Marshall · 2017

The build

Every RS-25 hot-fire test produces data from about 6,000 sensors that has to be assessed within seven days. On a five-intern team supporting the Space Launch System’s main engine, I built the PID Heat Map Tool, a MATLAB and Python tool with a full GUI that maps which sensor parameters the assessment plots use, how often and in which plots, so engineers can see coverage gaps and redundant analysis. Our team also wrote a script template and a worked LOX-system example so the next engineers know why each plot exists and how to read it.

  • MATLAB
  • Python
  • GUI Development
  • Data Assessment
  • Systems Engineering
  • Technical Documentation

Sonablate HIFU Probe

Product R&D Engineering Co-Op · SonaCare Medical · 2016–2018

The build

I worked on the Sonablate probe, which delivers precise, focused ablative energy into the prostate. The probe housing and the entire assembly were within my design scope, including its demanding medical sealing. I took the design from concept through SolidWorks models, 3D-printed and cast urethane prototypes, fabrication, validation testing and the test reports, and I set the cable specifications and drew the 2D/3D electrical routing.

  • Medical Devices
  • Housing & Assembly Design
  • Medical Sealing
